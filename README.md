# Task-28-Simple-Percentage-Analysis

Sample Superstore Sales Analysis

Tool: Microsoft Excel
Dataset: Sample Superstore

Objective

Calculate sales contribution percentages by category and present the results using a percentage table and charts.

Workbook

The complete project is available in:

simple_percentage_analysis.xlsx

Workbook Sheets

•
Percentage_Analysis — Category sales, contribution percentages, orders, quantity, profit, total check, and charts

•
Source_Data — Complete Sample Superstore source dataset

•
Calculation_Notes — Denominator explanation, formula, validation, and dataset information

Percentage Calculation

The contribution percentage is calculated as:

Plain Text


Category Sales ÷ Total Sales × 100



The denominator is the total sales across all categories in the Sample Superstore dataset. The percentage total is checked to ensure it equals 100%.

How to Use

1.
Download and open simple_percentage_analysis.xlsx in Microsoft Excel.

2.
Open the Percentage_Analysis sheet.

3.
Review the category sales and contribution percentages.

4.
Confirm that the total contribution percentage equals 100%.

5.
Review the charts and calculation notes.

6.
Use the Source_Data sheet to inspect the original records.

Interview Note

Percentage contribution explains how much each category contributes to a selected total. The denominator must always be stated so that the calculation is clear, accurate, and reproducible.
